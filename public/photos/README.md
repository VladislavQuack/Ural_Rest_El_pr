# Фотографии сайта

Все картинки сайта лежат в этой папке и подключены через `photoUrl()` из
`src/photo.ts`. Файлы, которых нет, показывают фирменную плитку «ФОТО СКОРО»
(`onPhotoError`), а не сломанную иконку — можно добавлять по одному, код трогать
не нужно.

Исходники лежат в `publoc/` (опечатка в названии папки из коммита `91c9913`);
в `public/photos/` — оптимизированные веб-копии. `hero.png` 11,4 МБ →
`hero.webp` 232 КБ (прозрачность сохранена).

## Пока заглушка «ФОТО СКОРО» ⏳

Добавьте файл с этим именем — и он появится сам:

- `dalnyaya-dacha-1.jpg` — Дальняя дача (карточка, галерея, таймлайн «Сегодня»)
- `about-intro.jpg` — блок «Больше 25 лет встречаем гостей» на «О нас»
- Галереи: `dikanka-2.jpg`, `dikanka-3.jpg`, `el-primo-2.jpg`, … — по 2–3 на
  каждое заведение (имя = `<id>-2.jpg` / `<id>-3.jpg`); таймлайн 2020 ждёт
  `gorky-2.jpg`.

Расширение должно совпадать с тем, что прописано в `src/data.ts`
(у заведений `-1` уже с реальным расширением: `.jpg` или `.webp`).
